Personal portfolio for Julián Galindo Mora. React + Vite SPA deployed on Vercel.

## Stack

- **Framework:** React 18 + Vite 5
- **Routing:** React Router DOM 6 (defined in `src/App.jsx`)
- **Styling:** Tailwind CSS 3 (`tailwind.config.js`)
- **Animation:** Framer Motion 11, GSAP 3, Three.js + React Three Fiber
- **i18n:** Custom `LocaleProvider` — all copy lives in `src/i18n/translations.js` (en/es)
- **Deployment:** Vercel (`vercel.json`)

## Key conventions

- **Never hardcode text in components.** All copy must go through `translations.js` and be consumed via the locale hook.
- **New projects** require an entry in `src/data/projects.js` (slug, i18n keys, accent color, skills, links) plus a new page under `src/pages/projects/` and a route in `App.jsx`.
- **Case studies** share one header (`CaseHero` in `src/components/CaseStudy.jsx`: kicker, title, summary, ficha, links) and end with `NextCase`. Site tokens only: no per-project palette or display font.
- **Shell** (`components/shell/`): `RouteBackground` (fixed landscape that fogs with the scroll), `SideNav` (links + the six networks as Plush Tiles), mobile foot with the networks, page swap in `AppShell`. No boxes behind text.
- **Fur pieces** (`components/fur/`): `PlushTile`, `FurButton` (`velour` primary, `mohair` secondary — the only two button kinds). At rest each is an image (baked in `assets/fur/` by `npm run bake:fur`, or snapshotted off-screen by `FurSnapshotter`); only the piece under the pointer/focus is a live WebGL canvas (`fur/live.js`).
- **Vendor ports**: `*Canvas.jsx` in `components/fur/`, `botanical/FlowerTypeScene.jsx` and `components/TumbleDeck.jsx` are GENERATED by `npm run port:vendor` from the untouched originals in `vendor/` plus a listed set of patches. Never edit them by hand; change the patch list in `scripts/port-vendor.mjs`.
- **Botanical Text** runs on hover for every `main h1, main h2` through one shared canvas (`components/botanical/host.js`); headings are plain text otherwise.
- **Concrete material**: class `.concrete` (texture from `scripts/make-concrete.mjs`).
- **Typography is fixed site-wide:** Libre Baskerville (`font-display`) for headings, Roboto Mono (`font-body`) for prose, Space Grotesk (`font-nav`) for labels, tags and buttons. Palette is the site's too (V3 §A: cold concrete, mist, moss, lichen, bloom).
